Authentication

Every request to the Lattice API carries a bearer token. Tokens are scoped to a project and expire after 30 days unless rotated.

Never ship a secret key in client-side code. Use a server route that holds the key.

Create a key

Open Project settings → Keys and choose New key. Copy it once; it is not shown again.

curl https://api.lattice.dev/v1/me \
  -H "Authorization: Bearer $LATTICE_KEY"
