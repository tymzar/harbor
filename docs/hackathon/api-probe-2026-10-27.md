Spot-checked boxes land on the real Debug, Import, Network-tab and Engine-select controls and the "Presses learned" tile. Visual/shape phrases match; UI-semantic names mostly do not. Usage reports `images_processed: 1` with zero tokens; price per image not yet looked up.

## Implications for the plan

- Spark via LiteLLM is viable as the proxy route; strict schema survives it.
- SAM is a visual-region detector, not a UI-semantics model. Use it to propose candidate boxes from a few shape prompts, map boxes to DOM via hit-testing, and let Spark name and group them. Do not ask SAM for "card" or "menu".
- One concept per request means several calls per page (~2 s each, parallelisable).
- Not yet tested: SAM through LiteLLM, third-party pages, scrolled/lazy content, mask decoding, SAM pricing.
